# occupied-hours
a demonstration flask app for setting values in shared memory for use by other apps. Outputs standard iCalendar format suitable for storing as a string in Redis.

## Features

- **Weekly calendar grid** - Click or drag to select occupied hours
- **iCalendar output** - Standard RFC 5545 format
- **Consecutive hour grouping** - Adjacent hours are merged into single events
- **BOS integrated** - writes
